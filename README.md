A CV library I made to create bots that are able to perform at superhuman levels on different [Human Benchmark](https://humanbenchmark.com/) tests, purely based on vision (no looking at HTML, etc.)

The main constraint in this project is for the program to contain as little preprogrammed resources as possible, and mainly acquire data in runtime, to avoid problems with resolution / fonts / etc. Also no machine learning, solutions should be as simple as possible.
